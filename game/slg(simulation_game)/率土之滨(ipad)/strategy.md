# 1 提升队伍战力的几种方法

## 1.1 战法

* 使用高星级武将，并且给武将配备高级的战法，并将战法升级到最高级;
* 给武将配适合自己的强力战法（要考虑战法的对象和目标距离，以及武将的位置，否则可能战法品质很好却没有发挥作用）可以大大增强队伍战力；
* 不在乎有多少5星武将，而要尽量让主开荒队变强，为此牺牲5星武将来拆解出合适的战法也是可以的。

## 1.2 兵种

转换武将兵种，兵种越高级稀有，武将战力越强。

## 1.3 配将策略

* 尽量使得队伍拥有多种加成，比如阵营加成，兵种加成，称号加成；
* 可以用攻略中的配将策略配将。

## 1.4 兵力

武将携带部队人数越多，战力越强。

## 1.5 宝物

给武将配备稀有的宝物，可提升战力。可以强化宝物来提升战力。

# 2 资源产量

## 2.1 如何不攻击别人快速提升资源产量

* 占领无人占领的5级地和与之相连的4级地，修建资源库。
* 加入同盟，有资源产量加成。

## 2.2 不断放弃低级地，占领高级地

## 2.3 建立资源库，辖制土地，以及建立采垦场

## 2.4 如何占领高级地

派出3个队伍在敌方兵力恢复以前连续攻击同一块地，可以占领该地。
